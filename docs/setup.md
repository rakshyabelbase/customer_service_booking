# Setup

## Prerequisites

- Node.js 20 or newer
- npm
- A modern web browser

## Installation

From the project directory, install the dependencies:

```bash
npm install
```

## Environment configuration

No environment variables or `.env` file are required. The application uses a browser-based mock API and stores data in `localStorage`.

## Running the application

Start the Vite development server:

```bash
npm run dev
```

Open the URL shown in the terminal, usually `http://localhost:5173`.

To create a production build:

```bash
npm run build
```

## Running the mock API

The mock API runs inside the application, so there is no separate API server or command to start. Running `npm run dev` starts everything required.

The DevToolbar can change the simulated network delay, force server errors, and reset the mock data.

## Running tests

Tests use Jest and React Testing Library. Run all tests with:

```bash
npm test
```

Other test commands:

```bash
npm run test:watch
npm run test:coverage
```

Tests are kept next to the related page or component in `src/features`. Shared test data and helpers are in `src/test-utils`.

The tests cover service loading, service errors, service details, booking validation, successful bookings, and booking conflicts.

The `coverage/` folder is generated by `npm run test:coverage`. It can be deleted safely and will be created again the next time coverage runs.
